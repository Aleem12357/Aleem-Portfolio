## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Aleem12357/muhammad-aleem-s-creative-hub.git
   cd muhammad-aleem-s-creative-hub
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:8080` (or the URL shown in your terminal) to view the site.

4. **Build for production**:
   ```bash
   npm run build
   ```
